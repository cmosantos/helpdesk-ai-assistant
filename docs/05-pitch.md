# 05 - Pitch Final

## Título

**HelpDesk AI Assistant: um assistente virtual para suporte técnico N1**

## Roteiro de Pitch

Em empresas, muitas pessoas usuárias enfrentam problemas simples no dia a dia, como dificuldade para acessar o Outlook, falha no Teams, problema com MFA, senha bloqueada, lentidão no computador ou dúvidas sobre abertura de chamados. Esses casos chegam com frequência ao suporte técnico e muitas vezes precisam de uma primeira orientação rápida antes da análise de um analista.

O HelpDesk AI Assistant foi criado para resolver esse problema de forma simples. Ele funciona como um assistente virtual de suporte N1, capaz de receber uma dúvida do usuário, consultar uma base de conhecimento organizada e responder com uma orientação clara, objetiva e segura.

A solução não tenta substituir o time de suporte. Pelo contrário, ela ajuda a reduzir dúvidas repetitivas, melhora a triagem inicial e orienta o usuário sobre os próximos passos. Quando o agente não possui informação suficiente, ele informa isso claramente e recomenda a abertura de chamado, evitando respostas inventadas.

Na prática, o usuário digita uma dúvida como “Meu Outlook não abre” ou “Meu MFA não chega no celular”. O sistema identifica o tema relacionado na base de conhecimento e retorna uma orientação inicial. Caso a dúvida esteja fora do escopo, o assistente responde de forma segura e direciona para atendimento técnico.

O diferencial do projeto está na aplicação prática da IA em um cenário real de TI. Ele mostra como bases de conhecimento, engenharia de prompts e regras de segurança podem ser combinadas para criar um assistente útil, confiável e alinhado à rotina de um Service Desk.

Como próximos passos, o projeto pode evoluir para uma interface web, integração com uma API de LLM, conexão com uma ferramenta de chamados e uso de artigos reais de conhecimento técnico.

O HelpDesk AI Assistant é uma primeira versão funcional, simples e educacional, mas representa uma aplicação realista de Inteligência Artificial no suporte técnico corporativo.

## Mensagem Principal

A IA não precisa começar substituindo processos complexos. Ela pode começar ajudando em tarefas simples, repetitivas e bem documentadas, gerando valor real para usuários e equipes de suporte.
